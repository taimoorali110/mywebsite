  # Sentiment Analysis for Movie Reviews

  This project provides a robust sentiment analysis solution that can classify movie reviews as positive or negative with high accuracy. The pipeline includes text preprocessing, feature extraction using TF-IDF, and classification using Logistic Regression, making it suitable for both research and production environments.

  ## Overview

  The project uses the Stanford IMDb Movie Reviews dataset containing 50,000 movie reviews with balanced positive and negative sentiment labels. The dataset is split into separate training and test sets for robust evaluation.

  ## Requirements

  Python 3.7 or higher

  Dependencies:
  numpy
  pandas
  scikit-learn
  matplotlib
  seaborn
  nltk
  tqdm

  ## Installation

  1. Clone the repository:
    git clone https://github.com/taimoorali110/sentiment-analysis-for-movie-reviews.git
  2. Install required packages:
    pip install numpy pandas scikit-learn matplotlib seaborn nltk tqdm

  ## Usage

  Open and run the `Pipeline.ipynb` notebook in Jupyter Lab or VS Code. The notebook guides through setup, preprocessing, feature extraction, model training, evaluation, and custom testing.

  ## Model Performance

  Accuracy: ~87-90% (varies by dataset size)
