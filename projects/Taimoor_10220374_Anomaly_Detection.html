# Simple Anomaly Detection (IoT) — Minimal Project

This minimal project trains an IsolationForest on synthetic sensor data (temperature, humidity, sound_volume) and exposes a simple Flask REST API to return anomaly scores.

Quick start:
python -m venv .venv
pip install -r requirements.txt
python train.py
python api.py

Endpoints:
POST /predict with JSON object(s) containing temperature, humidity, sound_volume.
