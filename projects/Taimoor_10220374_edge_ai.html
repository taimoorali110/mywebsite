# Face Analysis Edge AI Project

Multi-task deep learning model for age, gender, and expression recognition deployed on mobile edge devices using ONNX Runtime Web. Includes training scripts, export utilities, and a React Native mobile app for inference.

## Technologies
- Training: PyTorch
- Mobile: React Native (Expo)
- Inference: ONNX Runtime Web
