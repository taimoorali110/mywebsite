# Habit Tracker Application

A Python-based habit tracking application that allows users to create, manage, and analyze daily and weekly habits. Uses SQLite and Click for a CLI interface. Includes analytics, streak calculations, and a testing suite with pytest.

## Quick Start
1. Clone repo
2. python -m venv venv
3. pip install -r requirements.txt
4. python main.py load-sample
