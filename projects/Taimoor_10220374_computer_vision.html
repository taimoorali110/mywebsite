# Object Detection and Segmentation Project

This project demonstrates object detection and segmentation on video using YOLOv8, Mask R-CNN, and SAM. It includes setup instructions, usage examples, and evaluation utilities.

## Setup
1. Install dependencies: pip install -r requirements.txt
2. Place `input.mp4` in project root

## Usage
python main.py --model yolov8 --input input.mp4 --output output_yolov8.mp4
