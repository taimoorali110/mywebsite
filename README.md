# MyName — Portfolio

This is a modern, responsive portfolio website for a software developer.

Features
- Clean, Apple-like light design
- Mobile-first responsive layout
- Modern CSS animations and hover effects
- Portfolio tiles with individual project pages

Preview locally:

```bash
# from this folder
python3 -m http.server 8000
# then open http://localhost:8000
```

Customize `index.html`, `style.css`, and `script.js` to update content and styles.
